# Label of the Covariance Estimator

Describes the standard errors of a fit for printed output.

## Usage

``` r
vcov_label(object)
```

## Arguments

- object:

  \[mandatory\] (softcats) A fit returned by
  [`soft_lm()`](https://mtkurbucz.github.io/softcats/reference/soft_lm.md).

## Value

A character string.
