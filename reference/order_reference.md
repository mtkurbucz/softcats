# Put the Reference Category First

Reorders the columns of the probability matrix so that the reference
category comes first.

## Usage

``` r
order_reference(mat, reference)
```

## Arguments

- mat:

  \[mandatory\] (matrix) Class probabilities.

- reference:

  \[mandatory\] (character or integer) Reference category, by name or
  position.

## Value

The reordered matrix.
