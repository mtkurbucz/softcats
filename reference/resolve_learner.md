# Resolve the Learner Argument

Accepts a single learner or a list `list(m = , r = )`.

## Usage

``` r
resolve_learner(learner)
```

## Arguments

- learner:

  \[mandatory\] (softcats_learner or list) The `learner` argument of
  [`soft_lm()`](https://mtkurbucz.github.io/softcats/reference/soft_lm.md).

## Value

A list with the learners `m` and `r`.
